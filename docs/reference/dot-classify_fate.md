# Terminal fate of a declining (absorbed) trajectory (destination axis)

Resolves where the terminal cohort goes: dormancy (extinct, or it mostly
drops out of every final group – true death), convergence (it
concentrates in a single living trajectory: low destination entropy), or
divergence (it scatters across several: high entropy).

## Usage

``` r
.classify_fate(group, dest_entropy, dormant_share, th)
```
